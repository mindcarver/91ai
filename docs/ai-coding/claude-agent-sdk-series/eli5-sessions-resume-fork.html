CLAUDE AGENT SDK / 08 / 一页图解

恢复会话，找回的是什么？

找回的是对话历史。SDK 会保存之前的提问、工具调用和回答；下一次可以接上它，或复制一份历史走另一条路。

01 先留下能找到的历史

Agent 完成一次任务

例如，读完仓库并分析架构。接收结果时，记下这次任务的 session ID。

保存为会话历史提问 + 回答 + 工具调用及结果
session ID 是找回这段历史的号码

02 下一次，选一条路

A

continue

不填 ID → 找最近一段

适合一个目录里只跑一件事。多个任务交替时，“最近”可能不是你要的那次。

结果：接着原会话聊。

B

resume

指定 session ID → 精确找回

要继续某个明确任务，就保存并传入它的 ID。适合任务列表、失败后续跑。

结果：接着指定会话聊。

C

fork

指定 ID + fork → 复制历史

从同一段历史开出新会话，拿到新 ID；原会话不被新分支改写。

结果：两条对话各走各的。

让例子走一遍

原会话：已完成架构分析→ resume 原 ID：继续做安全审查/ fork 原 ID：另开一条性能审查支线

对话会接上或分叉

恢复时带回先前的对话；fork 会给复制出的对话一个新 ID。这是会话层的变化。

文件不会跟着分叉

恢复不会回滚文件。两个 fork 若在同一目录改代码，仍会碰到同一批真实文件；需要文件隔离时，为分支准备独立工作目录。

记住：session ID 找回对话；fork 复制对话。文件隔离要另做。

这张图省略了什么：跨机器恢复需要共享存储或搬运会话文件；关闭持久化后，不能指望下次从磁盘恢复。
